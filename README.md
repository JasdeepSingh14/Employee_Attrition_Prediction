# Employee_Attrition_Prediction

📊 Employee Attrition Prediction using Machine Learning

Predicting employee attrition is one of the most important applications of Machine Learning in Human Resource Analytics. This project leverages classification algorithms to predict whether an employee is likely to leave an organization based on workplace, demographic, and job-related factors. The project follows a complete end-to-end Machine Learning workflow including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and business insights generation.
